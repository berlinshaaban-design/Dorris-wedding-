# Dorris Wedding — Database & Analytics Project

**Academic Team Project | Ben-Gurion University**

A database design and analytics project based on the business processes of Dorris Wedding, an international online retailer offering bridal, bridesmaid, and evening dresses, including customizable designs.

The project examines how an e-commerce business can represent products, customers, orders, reviews, and search activity in a relational database and use that information for analysis.

## Project work

### Business process and data modeling
- Studied the online retail process and its data requirements.
- Identified the main entities and relationships, including dresses, customers, orders, reviews, and searches.
- Developed the database model across the academic project phases.

### SQL database development
- Wrote SQL table definitions and analytical queries.
- Worked with joins, grouping, subqueries, filtering, and set operations.
- Used SQL window functions including `ROW_NUMBER()` and `NTILE()` for analysis.

### Data preparation and reporting
- Prepared an Excel workbook for the project dataset.
- Included Tableau reporting materials as part of the project submission.

## Technologies

**SQL · SQL Server · Relational Database Design · Excel · Tableau**
